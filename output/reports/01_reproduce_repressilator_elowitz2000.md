## 2. 文献给出的模型（Box 1：确定性连续近似）

### 2.1 变量与机制
六个变量：三个抑制蛋白浓度 $p_i$ 与对应的三个 mRNA 浓度 $m_i$，$i \in \{\text{lacI},\text{tetR},\text{cI}\}$，对应抑制子 $j \in \{\text{cI},\text{lacI},\text{tetR}\}$（环状：LacI ⊣ TetR ⊣ CI ⊣ LacI）。

$$m_i\;(i=\text{lacI})\ \text{被}\ p_{cI}\ \text{抑制},\quad m_{tetR}\ \text{被}\ p_{lacI}\ \text{抑制},\quad m_{cI}\ \text{被}\ p_{tetR}\ \text{抑制}$$

这说明文献采用的是“对称假设”：三个抑制子除了 DNA 结合特异性外完全相同（原文明确说明）。

### 2.2 方程（时间以 mRNA 寿命为单位）
$$\frac{dm_i}{dt} = -m_i + \frac{\alpha}{1+p_j^{\,n}} + \alpha_0, \qquad
\frac{dp_i}{dt} = -\beta\,(p_i - m_i)$$

- $-\!m_i$：mRNA 降解（时间已用 mRNA 寿命无量纲化）；
- $\alpha/(1+p_j^n)+\alpha_0$：Hill 型转录抑制，$\alpha$ 为完全去阻遏时的最大转录速率，$\alpha_0$ 为启动子“漏表达”（leakiness），$n$ 为 Hill 系数（协同性）；
- $-\beta(p_i-m_i)$：翻译 + 蛋白降解的准稳态化简，$\beta=$ 蛋白降解率 / mRNA 降解率。

### 2.3 文献给出的参数（维数形式）
| 量 | 文献数值 | 来源 |
|---|---|---|
| 启动子强度（完全诱导） | $0.5$ transcripts s$^{-1}$ | Box 1 |
| 启动子漏表达（完全抑制） | $5\times10^{-4}$ transcripts s$^{-1}$ | Box 1 |
| 翻译效率 | 20 proteins / transcript | Box 1 |
| Hill 系数 $n$ | 2 | Box 1 |
| 蛋白半衰期 | 10 min | Box 1 |
| mRNA 半衰期 | 2 min | Box 1 |
| $K_M$（半最大抑制所需的抑制子数） | 40 monomers / cell | Box 1 |

### 2.4 我们为无量纲化所做的一步算术换算（已在 IR 的 assumptions 中登记）
时间和浓度按 Box 1 的规则无量纲化：时间以 mRNA 寿命为单位，蛋白以 $K_M$ 为单位，mRNA 除以翻译效率（20 proteins/transcript）。于是

$$\alpha = \frac{0.5\ \text{s}^{-1}\times 120\ \text{s}\times 20}{40}=30,\qquad
\alpha_0 = \frac{5\times10^{-4}\times120\times20}{40}=0.03,\qquad
\beta = \frac{\ln 2/10}{\ln 2/2}=0.2$$

**一致性检验**：$\alpha_0/\alpha = 10^{-3}$，正好等于文献图 1b 中曲线 C 所用的比值 $10^{-3}$ —— 说明该换算与原文自洽。

## 4. 数值复现：设置与结果

### 4.1 设置
- 求解：RK45，$t\in[0,200]$（无量纲时间单位 = 1 个 mRNA 寿命）。
- 初值（**我们假设**，非文献值）：$(m_{lacI},m_{tetR},m_{cI})=(1,0.3,0)$，$(p_{lacI},p_{tetR},p_{cI})=(0.2,0.05,0)$。
- 参数：$\alpha=30,\ \alpha_0=0.03,\ \beta=0.2,\ n=2$。

### 4.2 得到的动力学特征

| 特征 | 复现结果 |
|---|---|
| 解的定性类型 | **持续极限环（sustained limit cycle）**，无阻尼 |
| 周期（抑制蛋白 $p_{cI}$ 估计） | **31.5 个 mRNA 寿命单位** |
| 换算成分钟 | $31.5\times 2.9\ \text{min} \approx \mathbf{91\ min}$（把 1 寿命 = $1/\gamma_m = 2.9$ min）；若把寿命直接等同于 2 min 半衰期则为 63 min |
| 蛋白峰值 | $\approx 11.9\,K_M$，即 $\approx 470$ 个抑制子/细胞 |
| 蛋白谷值 | $\approx 0.20\text{–}0.25\,K_M$，即 $\approx 8\text{–}10$ 个抑制子/细胞 |
| 峰谷振幅比 | $\approx 50$ 倍（振幅“大”，与原文描述一致） |
| mRNA 峰值 | $\approx 15.8$（无量纲单位） |
| 三个蛋白的相位关系 | 依次错开 $\approx$ 1/3 周期（相邻峰值间隔 11.4、11.5 个时间单位 vs $T/3 = 10.5$）✔ |
| 对称定态（解析） | $p^\*$ 满足 $p = 30/(1+p^2)+0.03 \Rightarrow p^\* \approx 3.0$ |

### 4.3 与文献稳定性判据的对照
原文给出的判据为：定态在 $(\beta+1)^2 < \tfrac{3}{4}X^2+2X$ 时不稳定，其中 $X = \alpha n p^{n-1}/(1+p^n)^2$。代入 $p^\* \approx 3.0,\ n=2,\ \alpha=30$：

$$X = \frac{30\times 2\times 3.0}{(1+9)^2}=1.8,\qquad (\beta+1)^2 = 1.44 \;<\; \tfrac34 X^2+2X = 6.03$$

即参数点落在**不稳定区**，与图 1b 的“左下（不稳定）阴影区”结论一致，也与图 1c 显示的持续振荡一致。✔

### 5.1 关于周期偏差的讨论
1. **读出环节的低通滤波**：实验测的是 GFP（GFP-aav 半衰期 $\approx90$ min）而非抑制子本身。线性滤波不改变周期，但会衰减振幅、引入相位滞后——这不能解释周期偏长。
2. **$\alpha$ 的不确定性**：原文从未印出无量纲 $\alpha$；我们的 30 来自维数数值换算。$\alpha$ 变大通常会延长周期，若实际所用 $\alpha$ 更大，模型周期会向 150 min 靠近。
3. **蛋白稳定性**：原文明确写“period is determined mainly by the protein stability”。我们在自发构建模型中做了敏感性检验（见报告 02）：把 $\beta$ 由 0.2 降到 0.1（蛋白半衰期 20 min），周期由 $\approx84$ min 升到 $\approx110\text{–}114$ min，证实这一依赖性；要得到 150–160 min 需要更长的有效蛋白寿命。
4. **体内实际半衰期、质粒拷贝数、生长稀释、噪态**均未包含在 Box 1 的确定性模型中。

结论：**模型的定性行为（持续极限环、大幅错相振荡、不稳定区位置）被成功复现；定量周期比实验短约 2 倍**，差异来自参数换算不确定性与实验读出/生长效应。
