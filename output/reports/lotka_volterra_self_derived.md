## 1. 建模目标

用一个**最小但有代表性**的确定性 ODE 系统，刻画一个一维（无空间结构）生态系统中
**被捕食者（prey, X）** 与 **捕食者（predator, Y）** 两个种群的动态耦合，并展示：
- 两物种是否可能共存；
- 系统是否存在稳态、周期振荡；
- 振荡的周期、振幅与峰值/谷值特征。

## 2. 机制分析与建模假设（assumptions）

| # | 假设 | 生物学含义 |
|---|------|-----------|
| A1 | 封闭、均匀混合（well-mixed）种群，无空间结构、无年龄结构 | 可用常微分方程刻画总量，忽略迁移与斑块 |
| A2 | 无捕食者时，被捕食者按 Malthusian 指数增长，增长率 α | 食物资源充足、无环境容纳量限制 |
| A3 | 捕食作用遵从**质量作用（随机相遇）**规律，被捕食者被移除速率 ∝ X·Y | 捕食机会与两物种密度乘积成正比（I 型功能反应，无饱和） |
| A4 | 无被捕食者时，捕食者按常数人均死亡率 γ 呈指数衰减 | 捕食者没有替代食物来源 |
| A5 | 捕食者把消耗掉的被捕食者按常数转化效率 δ 转成新个体 | 能量/生物量转化效率恒定，无时滞 |
| A6 | α, β, δ, γ 均为常数，不随时间或密度变化 | 环境恒定、确定性 ODE |
| A7 | 种群足够大，忽略人口统计随机性 | 用确定性模型代替随机过程 |

## 3. 方程

$$\frac{dX}{dt} = \alpha X - \beta X Y$$

$$\frac{dY}{dt} = \delta X Y - \gamma Y$$

**逐项生物学含义：**

- `+alpha*X`：被捕食者的自然增长（A2）。
- `-beta*X*Y`：被捕食造成的损失（A3）。
- `+delta*X*Y`：捕食者因捕食而获得的增长（A3 + A5）。
- `-gamma*Y`：捕食者的自然死亡（A4）。

## 4. 参数与初值（合理取值）

| 参数 | 含义 | 数值 | 单位 |
|------|------|------|------|
| α (alpha) | 被捕食者内在增长率 | 1.1 | 1/time |
| β (beta) | 捕食/攻击率系数 | 0.4 | 1/(individuals·time) |
| δ (delta) | 捕食者转化效率 | 0.1 | 1/(individuals·time) |
| γ (gamma) | 捕食者死亡率 | 0.4 | 1/time |

**初值：** X(0) = 10，Y(0) = 5；**时间范围：** t ∈ [0, 60]。

> 取值合理性：δ（转化效率 0.1）< β（被捕食者被移除 0.4），符合“并非所有被捕食者生物量
> 都能转化为捕食者”的能量损耗常识；α=1.1、γ=0.4 使两物种在一个数量级内的时间尺度上振荡。

## 5. 理论平衡点（解析）

令两式右端为 0，得到**非平凡共存平衡点**：

$$X^* = \frac{\gamma}{\delta} = \frac{0.4}{0.1} = 4.0, \qquad Y^* = \frac{\alpha}{\beta} = \frac{1.1}{0.4} = 2.75$$

该平衡点为 **中性中心（neutral centre）**：线性化特征值为纯虚数
± i·√(αγ) = ± i·√0.44 ≈ ± 0.663 i，因此小扰动下不增不减，**不趋向也不远离**平衡点。

## 6. 数值模拟结果

用 RK45 对上述 ODE 求解，得到如下特征（见 `output/simulation_...self_derived.json` 与 PNG 图）：

| 量 | 数值 |
|----|------|
| 终态 (t=60) | X = 1.170，Y = 1.250 |
| X 峰值 | 13.676（t ≈ 42.44） |
| Y 峰值 | 6.155（t ≈ 43.91） |
| X 谷值 | 0.509（t ≈ 3.66） |
| Y 谷值 | 0.916（t ≈ 51.00） |
| 振荡周期（估计） | X: ≈ 10.79，Y: ≈ 10.78 |

**观察与解读：**

1. **持续振荡、无阻尼衰减**：X 与 Y 均呈周期性波动且振幅不随时间衰减，这与
   Lotka–Volterra 的“中性中心”理论一致——系统存在一个守恒量
   `V = δX − γ ln X + βY − α ln Y`，轨道是围绕平衡点 (4, 2.75) 的闭合曲线。
2. **相位滞后**：被捕食者 X 先达到峰值（t≈42.4），捕食者 Y 随后达峰（t≈43.9），
   相位差约为四分之一周期，符合“被捕食者先增多 → 捕食者食物充足后增多 →
   捕食压力增大使被捕食者减少”的经典捕食者–被捕食者滞后关系。
3. **周期与理论吻合**：数值周期 ≈ 10.8，与线性化/小振幅近似
   `T = 2π/√(αγ) ≈ 9.47` 同量级；数值周期略大是因为该轨道振幅有限，非线性使周期随振幅增大。
4. **共存而非灭绝**：两物种长期共存，围绕 (X*, Y*) = (4, 2.75) 振荡，未出现任一物种灭绝。

## 7. 局限性与下一步

**局限：**
- 无被捕食者环境容纳量（Logistic）项 → 现实中常需加入 `−σX²`。
- 无捕食者饱和（II/III 型功能反应）→ 无 `X·Y/(1+hX)` 形式。
- 无时间延迟、无空间扩散、无随机性。
- 参数为**示意性合理取值**而非拟合真实数据。

**下一步建议（如何标定/扩展）：**
1. 若有真实时间序列，用最小二乘 / 贝叶斯推断标定 α, β, δ, γ（注意 LV 模型振幅依赖初值，需谨慎）。
2. 加入 Logistic 增长项 σ 与功能反应（Rosenzweig–MacArthur），研究“富集悖论”（paradox of enrichment）。
3. 加入空间扩散 → 反应扩散 PDE，考察行波/图灵斑图。
4. 引入随机性 → 出生-死亡随机过程或带噪声的 SDE，研究随机灭绝风险。
