## 1. 文献给出的数学模型

三个抑制子基因构成环状负反馈：LacI ⊣ tetR，TetR ⊣ cI，CI ⊣ lacI（3 个抑制子，奇数环）。
对称性假设下（三个抑制子除 DNA 结合特异性外完全一致），六个耦合一阶 ODE：

```
dm_lacI/dt = -m_lacI + a/(1 + p_cI^n)   + a0
dm_tetR/dt = -m_tetR + a/(1 + p_lacI^n) + a0
dm_cI/dt   = -m_cI   + a/(1 + p_tetR^n) + a0
dp_lacI/dt = -b (p_lacI - m_lacI)
dp_tetR/dt = -b (p_tetR - m_tetR)
dp_cI/dt   = -b (p_cI   - m_cI)
```

生物学含义：
- `a/(1+p_j^n) + a0`：启动子被抑制子 p_j 以 Hill 函数抑制后的转录强度；`a0` 为漏表达（leakiness），`n` 为协同性（Hill 系数）。
- `-m_i`：mRNA 的一阶降解（时间以 mRNA 寿命为单位，故系数归一化为 1）。
- `b(m_i - p_i)`：以 mRNA 为模板的翻译生产与蛋白一阶降解，`b` = 蛋白降解速率 / mRNA 降解速率。

**无量纲化**（原文）：时间以 mRNA 寿命为单位；蛋白浓度以 K_M（半最大抑制所需抑制子数）为单位；
mRNA 浓度以翻译效率为单位。

### 解析稳定性验证（与图 1b 对照）

稳态由 p = a/(1+p^n) + a0 给出，数值解 p* ≈ 3.0（K_M 单位）。
线性化耦合强度 k = a n p*^(n-1)/(1+p*^n)² ≈ 1.76。
六变量 Jacobian 为循环矩阵，特征方程 (λ+1)³(λ+β)³ = -k³β³，取其复根分支解得
**λ = +0.028 ± 0.243 i（Re λ > 0）** → 稳态不稳定，发生 Hopf 分岔，
小振荡周期 2π/0.243 ≈ 26 个 mRNA 寿命，与数值积分的 ~30 一致。
→ 与原文“该参数落在图 1b 的不稳定区（稳态失稳 → 持续极限环）”的结论一致。

**差异的合理原因**（不修改模型，仅作解释）：
1. 实验读数是 GFP 荧光：GFP-aav 半衰期约 90 min、氧化成熟需要时间，报告分子对振荡起低通滤波作用，
   会把表观周期拉长、抑制高频成分（原文 Methods 明确提到此限制）。
2. 原文图 1c 所用 α 与图 1b 的“×”点具体数值未逐字给出；α 越大 → 振幅越大、周期随蛋白稳定性变化。
3. 实验体系存在质粒滴定、细胞生长/分裂、噪声等，确定性模型未纳入（原文用随机模拟说明噪声使自相关时间降为约 2 个周期）。
