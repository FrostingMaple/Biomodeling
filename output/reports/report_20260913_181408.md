## 4. 自发构建的模型方程（ODE）

定义物种：
- **E**：活性 Cas9-tracrRNA:crRNA 双 RNA 引导内切酶复合物
- **S**：含匹配 protospacer 与 PAM 的完整靶 dsDNA 底物
- **C**：酶-底物三元切割复合物（含 R-loop）
- **P**：被双链断裂后的 DNA 产物

方程（`d·/dt = ...`）：

```
dE/dt = -k1·E·S + k⁻¹·C + kcat·C
dS/dt = -k1·E·S + k⁻¹·C
dC/dt =  k1·E·S - k⁻¹·C - kcat·C
dP/dt =  kcat·C
```

生物学含义逐项说明：
- **-k1·E·S**：酶与底物的结合（含 PAM 识别、互补链种子区杂交与 R-loop 成核）。文献表明该步骤依赖 PAM(Mg²⁺ 存在下) 与种子序列。
- **+k⁻¹·C**：酶-底物复合物的可逆解离。
- **+kcat·C / -kcat·C**：催化性双链切割步骤——把复合物转化为产物，并释放（回收）酶 E，这是多周转的机制来源。
- **dP/dt = kcat·C**：切割产物累积速率。
